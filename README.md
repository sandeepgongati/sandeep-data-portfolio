# Sandeep Gongati - Data Engineer Portfolio

This is a self-contained, responsive personal portfolio site. Open `index.html` in a modern browser to view it.

## Included

- Professional profile and animated cloud/ETL visual design
- Experience, project, skills, credential, education, and contact sections
- Direct Databricks credential-verification link
- Responsive mobile navigation

The hero visual was generated for this website as a generic data engineer illustration; it is not intended as an identity-accurate portrait.
